# 物理仿真与算法实验目录

分阶段开发路线（不造全栈声学/粘连万能仿真器，聚焦高杠杆物理机理）：

1. **Stage 1（MuJoCo 3.x 硬件与物理机理门禁）**：
   - `Gate 1`：真实 CAD 贴屏避碰与全闭合不伤 GelSight Mini 胶面扫掠检查；
   - `Gate 2`：PET 软膜 vs. 0.30 mm 钢化玻璃膜剥离角控力与最小安全弯曲半径 $R \ge 70\text{ mm}$ 约束验证；
   - `Gate 3`：塑料暗卡扣 Snap-Through 5 ms 阻力归零瞬态卸力对比（30 Hz 视觉位控 vs. 250 Hz 高频护栏）。
2. **Stage 2（多卡 A100 + DGX Spark 核心物理智能算法）**：
   - 0.3 s 敲击/轻擦在线辨识工具传递函数 $H_{\text{tool}}(\omega)$ 与材料脆度隐变量 $z$；
   - 200~500 Hz 高危临界事件过程打分与 `< 5 ms` 退让/降角/卸力恢复闭环。
