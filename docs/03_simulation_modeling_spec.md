# 03. 真实 CAD 到物理仿真建模规范（先验证可行性，再批量下单）

> **核心目标**：在花钱加工与采购前，先把真实外购件与自制快换指座的 **真实 CAD 装配模型** 导入物理仿真器（**先 MuJoCo 做单机精细接触验证 $\rightarrow$ 再上多卡 A100 跑 Isaac Lab / MuJoCo MJX 大规模并行试错**），在仿真里验证几何是否干涉、力学是否合理、能否真正把扑克牌“拱起来 / 铲起来 / 单张搓离”。

---

## 1. 仿真器选型策略（两阶段组合）

| 阶段 | 推荐引擎 | 为什么选它 | 核心任务 |
| :--- | :--- | :--- | :--- |
| **Stage 1：单机精密接触与可行性验证** | **MuJoCo 3.x**（本机已有 `mujoco-3.10.0`） | 极度适合微米/毫米级薄片接触、柔性铰链屈曲、可精确读出每个接触点的法向/切向力与悬臂指甲关节力矩；调试周期以秒计 | 导入真实 CAD 碰撞体，跑通 4 项硬件可行性单元测试，验证不同指甲参数与倾角是否真的能铲起/拱起薄片 |
| **Stage 2：多卡 A100 大规模并行试错与 Co-Design** | **Isaac Lab** 或 **MuJoCo MJX / Warp** | 多卡 A100 可同时开数千个并行环境，支撑域随机化（桌面摩擦、牌刚度、多层粘连）+ RMA 隐变量 $z$ 训练 + 过程打分器训练 + Co-Design 参数扫描 | 大规模仿真训练策略、过程打分器与 Real-to-Sim 物理残差对齐 |

## 2. 真实 CAD $\rightarrow$ URDF / MJCF 导出规范

当你在 SolidWorks / Fusion360 中完成真实商用件（电爪、GelSight Mini、D405、XL330）与自制指座的装配后，请严格按以下规范导出到 `assets/`，避免仿真出现“穿模”或“碰撞体过粗卡死”：

### 2.1 Visual Mesh vs. Collision Mesh 严格分离
- **Visual Mesh**（`.stl` / `.obj`）：保留清晰的外观细节，用于渲染与 D405 相机视角检查。
- **Collision Mesh**：
  - **电爪主体、D405 外壳、XL330 壳体**：使用凸包分解（CoACD / V-HACD）或简单包围盒（Box），专门用来**检测是否撞到桌面（贴桌避碰）**；
  - **左指弹性指甲刃口（极关键！）**：**严禁使用粗糙的自动凸包**（凸包会把 0.2 mm 刀刃钝化成 2 mm 厚砖块，永远铲不进 0.3 mm 扑克牌！）。必须用**精确参数化薄板原语（thin box / wedge）**，并在厚度方向保持真实几何尺寸，同时适当调小求解器 `margin` 与 `solref`；
  - **右指视触觉硅胶面 / 搓轮**：使用光滑圆柱或带圆角长方体，并单独赋予高摩擦系数（$\mu_{\text{pad}} \in [0.8, 1.5]$）与软接触参数（`solref`/`solimp` 模拟硅胶柔顺压陷）。

### 2.2 弹性悬臂指甲的物理建模（不用昂贵有限元也能极准！）
在刚体/多体仿真中，不要直接用慢速 FEM 模拟一块 0.2 mm 钢片，推荐用**等效集中参数模型（Lumped-Parameter Compliant Hinge）**：
- 将弹性指甲沿自由伸出长度 $L$ 离散为 **1～2 段刚性薄片**，在指甲根部（固定夹持处）放置一个绕 Y 轴（垂直于弯曲平面）的 **旋转铰链（Revolute Joint）**；
- 铰链的等效扭转刚度由悬臂梁刚度解析给出：
  $$k_\theta \approx k_{\text{tip}} \cdot L^2 = \frac{3 E I}{L} = \frac{E b t^3}{4 L}$$
- **天然好处**：
  1. 在仿真里直接读取该根部铰链的**瞬时关节角度 $\theta_{\text{nail}}$ 和弹性恢复力矩 $\tau_{\text{nail}} = k_\theta \theta_{\text{nail}}$**，这就是**真实指甲背面应变片（Strain Gauge）的完美仿真代理信号**！
  2. 对 $\tau_{\text{nail}}$ 做一阶高通差分（$\Delta \tau / \Delta t$）或碰撞冲量脉冲提取，即为 **PVDF 压电薄膜的高频撞边脉冲仿真信号**！

### 2.3 可屈曲起拱、可叠放剥离的“薄片扑克牌”建模
单块纯刚体薄片无法弯折起拱。为了在仿真中同时支持**① 弯曲起拱（Buckling）**、**② 刚性硬卡不可弯**、**③ 多层叠放摩擦分离**，推荐两种方案：
- **方案 A（推荐，速度极快、适合并行 RL）—— 多段弹性铰链薄片（Articulated Elastic Sheet）**：
  - 将一张 $88 \times 63 \times 0.3\text{ mm}$ 的扑克牌沿长边离散为 $N = 8 \sim 12$ 条细长刚体薄片，相邻薄片之间通过带扭转刚度 $k_{\text{sheet}} = \frac{E_{\text{card}} W h^3}{12 \Delta l}$ 和轻微阻尼的旋转铰链串联；
  - 通过单一超参 `sheet_bending_stiffness` 即可无缝切换：**软餐巾纸/A4 纸（极低 $k$） $\leftrightarrow$ 扑克牌（中等 $k$） $\leftrightarrow$ 硬质 PVC 银行卡（极高 $k$）**！
  - 多层叠放只需在 Z 方向按 $h = 0.3\text{ mm}$ 间距堆叠 2～5 张同样的薄片，并独立设置**桌面-底牌摩擦 $\mu_{\text{table}}$** 与 **牌-牌间摩擦 $\mu_{\text{sheet}}$**（甚至加入微小粘附力/法向吸附偏置模拟静电或沾水粘连）。
- **方案 B（MuJoCo 3.x 高保真验证）—— `flexcomp` 2D 弹性壳网格**：
  - MuJoCo 3.x 原生支持 `flexcomp` 薄壳（Shell）屈曲，适合在 Stage 1 单机验证极端柔软薄片（如二维任意方向弯折的纸张/布料），但并行速度略慢于方案 A。

### 2.4 仿真步长与数值稳定性注意项
- 由于薄片厚度仅 $0.25 \sim 0.3\text{ mm}$、指甲厚度仅 $0.15 \sim 0.3\text{ mm}$，标准 `dt = 0.002 s` 容易出现高速穿透；
- **Stage 1 推荐配置**：`dt = 0.0005 s ~ 0.001 s`（1~2 kHz 物理步长，正好与指甲 1 kHz 传感同步！），启用 `noslip_iterations`（MuJoCo）以准确模拟静摩擦锁死与微搓滑移临界点。

## 3. 硬件下单前的 4 项仿真可行性单元测试（Pass / Fail 门禁）

在仿真中导入真实 CAD 导出的 `NewGripper` 模型后，必须依次跑通以下 4 项物理单元测试；全部通过后，说明机械几何尺寸与力学参数完全自洽，可直接发图纸加工与采购：

| 测试编号 | 测试场景 | 物理验证内容 | 通过标准（Pass Gate） |
| :--- | :--- | :--- | :--- |
| **Test 1** | **几何贴桌扫掠与零干涉测试** | 末端在 $\alpha \in [15^\circ, 35^\circ]$ 倾角下贴桌滑行、全闭合至 0.2 mm | 电爪外壳、D405、视触觉外壳全程与桌面接触力为 0；全闭合时指甲刃与视触觉胶面无自碰 |
| **Test 2** | **高摩擦桌面起拱拾取（Buckling）** | $\mu_{\text{table}} = 0.8$（橡胶垫/木桌），中等刚度扑克牌置于桌面中央 | 双指放平下压 + 切向挤压，薄片中央拱起高度 $\ge 4\text{ mm}$，随后顺利夹起 |
| **Test 3** | **光滑玻璃桌硬卡楔入（Nail-Wedge）** | $\mu_{\text{table}} = 0.15$（玻璃桌），高刚度硬银行卡置于桌面中央 | 右指轻压锚定 + 左指立起 20° 弹性指甲贴桌滑行，指甲产生 0.3~0.8 mm 弹性挠度并成功铲入卡底，根部力矩脉冲信噪比清晰 |
| **Test 4** | **多层叠牌单张搓离（Singulation）** | 堆叠 3 张扑克牌，$\mu_{\text{sheet}} = 0.35$，测试普通叠放与模拟高粘连（$\mu_{\text{sheet}} = 0.75$） | 微搓/非对称运动能稳定仅移动顶层第 1 张牌（与第 2 张产生 $\ge 8\text{ mm}$ 错位），且可从力矩/触觉代理信号中区分 1 张 vs. 2 张同时移动 |
