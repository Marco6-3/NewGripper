# 01. 硬件架构：YUBI 复刻魔改、2 万元 BOM 与 CAD 可行性校核

> **核心策略**：30% 机电投入不造整爪轮子。**无本体采集全栈复刻并魔改 Toyota YUBI（`toyota/yubi-hw` + `airoa-org/yubi-sw`）**；**部署端使用工业级高刚度底座（YUBI 原版 Dynamixel XM430 或大寰工业精密电爪）**；所有机电创新集中在**两端物理共用的“实体指尖/声振听诊工具盒”**。  
> **宿主硬件前置**：实验室采购工业协作臂（节卡 Kargo10/50/S³ 或新松多可，负载 $\ge 5\text{ kg}$，重复精度 $\pm 0.05\text{ mm}$）+ **腕部自带六维力传感器** + 多卡 A100 + 128GB DGX Spark；本清单支配独立 **20,000 RMB** 末端改造预算。

| 对比维度 | **YUBI（选定母版）** | **Specialist (`specialist-ai`)** | **Flash ALOHA** |
| :--- | :--- | :--- | :--- |

## 2. 系统总体构型：1 主动 DOF + 共用实体“声-振-触觉”指尖盒

### 2.1 自由度策略（A 版先行，克制严谨）
- **首版严格采用 1 主动开合 DOF + 6/7-DOF 机械臂手腕 + 被动弹性撬片/工具**。
- **原因**：YUBI 依赖拇指与食指直接贴合控制开合，1 主动 DOF 能保持 100% 人类自然手感；同时工具夹持（薄钢撬片、硅胶刮板、金属撬棒、尖镊子）与贴膜/赶泡/撬边/揭膜动作主要由 6-DOF 手腕精准完成。右指快换背板预留模块接口，仅在后续失败日志明确指向独立送料需求时，才考虑扩展 B 版快换滚轮盒（参考 `Rice-RobotPI-Lab/Roller-Rings`）。

### 2.2 核心创新结构：Physical Tip-Cartridge Swapping（两端共用同一对实体盒）
**严禁在 YUBI 手持端和机械臂部署端各 3D 打印一副“外形相同”的指尖/工具夹！**  
微米级贴膜撬边与高频声振传递对金属弹片预弯、硅胶微磨损、压电耦合预紧力极度敏感。因此两端均加工带**圆销 + 菱形销精密定位与预紧压板**的快换背板（左右防呆），采数完毕直接把**同一对实体指尖/听诊盒**拆下装到机械臂部署端：

1. **声-振听诊工具耦合盒（Tool-Stethoscope Cartridge —— 核心机电创新）**
   - **工具零改装**：通过标准快夹钳口稳固夹持任意市面 5 元金属工具（0.15~0.25 mm 薄钢撬片/铲刀、贴膜硅胶刮板、电子金属撬棒、不锈钢尖镊子）；
   - **高保真传振 + 机械臂隔振**：工具金属柄经硬质铝合金声学耦合块直连**宽带接触式压电/MEMS 振动传感器（20~48 kHz）**；在指座与电爪本体之间加入**弹性隔振垫片（如 Sorbothane/丁基橡胶阻尼层）**，阻断工业协作臂减速器与电爪电机的本底振动串扰；
   - **静态弯矩通道**：在薄钢撬片/弹性悬臂根部贴装 **350Ω 金属箔应变片**（$\ge 1\text{ kHz}$ 采集），独立测量静态下压挠度与撬边力矩。
2. **微触觉柔顺指尖盒（Tactile-Compliant Cartridge）**
   - 参考 [`actuated-umi/actuated-umi-gripper`](https://github.com/actuated-umi/actuated-umi-gripper) 的 `assembly/actuated-UMI-v2-assy.step` 抽取 **GelSight Mini** 托架与线缆保护结构；
   - 用于**透明膜直接捏持、手机边框触觉边缘对准、PET 软膜防皱张力与局部滑移观测**；
   - 撬边/铲硅片工况下，可与对侧声-振听诊工具盒搭配，形成“单侧薄钢弹性撬片/刮刀 + 对侧柔顺微触觉指腹”的复合形态，**一把末端完成贴、刮、撬、揭全闭环，无需频繁更换整套夹爪**。

### 2.3 严格解耦的四层物理感知分工（规避力学盲区）

| 感知通道 | 采样频率 | 负责物理量（严禁混用职责） |
| :--- | :---: | :--- |
| **1. 腕部六维 F/T（主机自带）** | 500 Hz+ | 宏观贴屏/贴桌法向压力（赶气泡恒力控制）、揭膜宏观剥离张力与外力防撞保护。<br>*注意：两指夹持内力在手腕处相互抵消，腕部 F/T 测不到夹持内力！* |
| **2. 工具/撬片根部应变片** | 1~2 kHz | 静态与准静态悬臂弯曲载荷（贴屏过盈量、顶死膜边阻力趋势）。<br>*严禁使用 80 Hz 的 HX711，必须用仪放 + Teensy 4.0 / 高速 DAQ！* |
| **3. 钳口宽带接触声振 / PVDF** | 20~48 kHz | **毫秒级高频物理指纹**：底板空滑 vs. 刮气泡 vs. 进缝进气 vs. 顶死脆边高频阻滞微震 vs. **钢化膜/硅片微裂纹前兆与卡扣崩开突跳**；并用于 0.3 s 敲击辨识工具传递函数 $H_{\text{tool}}(\omega)$。 |
| **4. 视触觉（GelSight Mini）+ 近景相机（D405）** | 25~30 Hz | GelSight Mini 观测透明膜局部滑移与接触分布（不承担毫秒级防撞保护）；D405 提供近距宏视角引导（7~50 cm）。 |

只从 **2 个母版仓库** 出发，避免碎片化拼凑：
- **手持骨架母版**：[`toyota/yubi-hw`](https://github.com/toyota/yubi-hw)（下载本地 STEP + BOM CSV + ROS2 驱动 [`airoa-org/yubi-sw`](https://github.com/airoa-org/yubi-sw)）；

| 需改动零件 | 具体设计要求 |
| :--- | :--- |
| **1. YUBI 手持强化骨架与遮手挡板** | 保留 YUBI 拇指/食指自然贴合顺应结构与 ESP32-C6/AS5601 布局；针对挂载实体盒增重，适当加厚顺应连杆并改用碳纤尼龙打印；在腕部相机前方增加轻量遮手小挡板（配合采数戴纯黑手套），消除近景相机人手视觉域差。 |
| **2. 双端共用定位销快换背板** | 手持 YUBI 端与部署工业电爪端各做适配背板，正面采用完全一致的**基准面 + 圆销/菱形销 + 预紧压板**（左右防呆），确保实体指尖盒换装后几何偏置可忽略。 |
| **3. 左盒：声-振听诊工具耦合盒** | 支持快速夹紧不同厚度薄钢撬片/刮板/撬棒；内部硬耦合宽带压电/振动传感器，弹性撬片根部留应变片贴装槽与机械硬限位防折弯，背板侧加隔振阻尼层隔离机械臂电机噪声。 |

| **5. 工具/指尖快换安全几何边界** | 在 SolidWorks 中以手机玻璃屏 $z = 0$ 为基准面，逐项验证 15°~40° 倾角下撬片入缝、刮板推压与全闭合夹膜时的零自碰（严禁锋利薄钢撬片在闭合时刮伤右指 GelSight Mini 透明胶面！）。 |

## 5. CAD 装配期必过的 7 项物理可行性门禁

1. **贴屏避碰校核**：整指保持 35°~45° 高倾角抬高电爪/GelSight 外壳，同时薄钢撬片向前预弯成 15°~20° 浅贴屏楔角，确保电爪、D405、Mini 外壳全过程离屏 $\ge 5\text{ mm}$；
2. **全闭合零伤胶校核**：夹持 0.15 mm 透明膜闭合至最小间隙时，左盒薄钢刃与右盒 GelSight 透明胶面必须有明确避让错位，零刮伤风险；
3. **撬片弹性挠度与安全系数**：运行 `python scripts/tool_and_peel_mechanics.py`，确保 2 N 下压力下挠度在 0.3~0.8 mm、抗屈服安全系数 $\text{SF} \ge 2.0$；
4. **声学隔振实测验证**：安装后在机械臂空载运动下录 10 秒本底频谱，确认隔振垫使电机噪声与工具尖端刮擦信号的信噪比（SNR）$\ge 15\text{ dB}$；
5. **手持端人机工学**：YUBI 装上实体盒 + D405 + Quest 控制器后，先用配重块盲测连续示范贴膜/揭膜 20 分钟不酸痛；
6. **线缆应力释放**：GelSight USB、应变片微细引线、压电屏蔽线在指端和前臂分别做双点应力释放，避免反复开合断线或引入摩擦伪音；
7. **ROS 2 毫秒级对时**：在 DGX Spark 上实测 Quest 6-DOF、腕部六维力、20 kHz 声振、1 kHz 应变与 D405/Mini 的端到端时间偏移，并做实测时延标定补偿。
