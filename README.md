# NewGripper: YUBI-Based Acoustic-Vibrotactile & Tactile Platform for Fragile Thin-Layer Manipulation

> **旗舰主线**：**手机贴膜（全透明软膜/脆性钢化膜对齐贴合 + 刮板赶气泡 + 0.2 mm 盲缝无损撬边 + 防脆断完整揭膜）** + **跨领域泛化（实验室超脆硅片无损铲取 & 电子卡扣外壳防过冲撬开）**。  
> **系统配比**：**30% 现成开源改装机电**（复刻魔改 Toyota **YUBI** 无本体手指贴合采集 + 两端共用实体“声-振-触觉”快换指尖/听诊工具盒）+ **70% 高频物理智能算法**。  
> **目标节点**：1 年内冲击机器人顶会（冲刺 **CoRL 2027** / 主攻 **ICRA 2028**）。

---

## 1. 为什么做这个课题？（纯视觉 VLA 的绝对物理盲区）

现有的无本体示教平台（UMI、YUBI、Specialist、FreeTacMan）与视觉大模型（VLA）在常规刚体抓取上表现亮眼，但在**“光学盲区 + 亚毫米接触相变 + 脆性临界断裂”**任务上集体失效。以**手机贴膜与完整无损揭膜**及**超脆硅片无损铲取**为例：

1. **光学全盲**：钢化玻璃膜与手机屏幕均为**全透明 + 镜面强反光**，RGB 相机分不清 0.2 mm 边缘缝隙与残留微气泡，深度相机（如 RealSense）在玻璃表面直接输出噪点空洞。
2. **直触式视触觉隔物失效**：GelSight Mini / DIGIT 等直接接触式视触觉一旦拿起**薄钢撬片、硅胶刮板、金属撬棒、不锈钢尖镊子**，传感器无法直接贴合目标接触点，必须依赖通过刚性工具柄传导回夹爪的**高频声学与微振动（10~48 kHz）**。
3. **毫秒级脆性断裂与临界失稳（Snap-Through）**：
   - 撬边角度太陡或顶死膜边多压 1 N $\rightarrow$ **脆钢化膜 / 实验室脆硅片当场崩边碎裂**；
   - 揭钢化膜时弯曲曲率半径小于临界值（约 $35\text{–}50\text{ mm}$）$\rightarrow$ **“啪”一声裂成蜘蛛网**；
   - 金属撬棒撬开暗卡扣的 5 ms 阻力归零瞬间 $\rightarrow$ 30 Hz 视觉与普通力控来不及卸力，直接捅碎内部脆弱器件。

## 2. 论文核心叙事：打通亚毫米脆性接触的“三重物理断层”

本项目不将创新押注在“发明另一种特殊形状手指”，而是提出一套面向无本体示教与脆性接触操作的系统级解法：

1. **断层 ① 微观接触界面与隔物感知断层 $\rightarrow$ YUBI 魔改 + 共用实体指尖/听诊盒（30% 硬件）**
   - 放弃离线 SLAM 易漂移的 Specialist 方案，基于 **Toyota YUBI (`toyota/yubi-hw` + `airoa-org/yubi-sw`)** 构建手指贴合无本体采集端（Meta Quest VR 抗反光 6-DOF 追踪 + 原生 ROS 2 实时同步总线）；
   - 提出 **Physical Tip-Cartridge Swapping（两端物理共用同一对实体指尖/听诊工具盒）**，采集端与机械臂部署端通过定位销快换背板拆装同一对实体前端，消除 3D 打印误差与微磨损带来的界面 Gap；
   - 钳口集成**声学高保真耦合 + 电机隔振结构**与**宽带接触声振/应变传感**，**无需改装工具**即可把任意 5 元薄钢撬片、刮板、撬棒、镊子变为机器人的神经延伸；同时保留单侧快换 GelSight Mini 视触觉用于直接捏膜对齐与局部滑移观测。
2. **断层 ② 视觉欠定与跨工具动力学断层 $\rightarrow$ 主动声学/微力探针与隐变量 $z$（70% 算法 ①）**
   - 通过前 0.2~0.3 s 轻敲/轻擦主动探针，在线辨识当前工具频响传递函数 $H_{\text{tool}}(\omega)$ 与隐藏材料属性 $z_t$（PET 软膜 vs. 脆钢化玻璃膜 vs. 脆硅片、粘胶剥离强度），实现跨工具、跨脆度零样本自适应策略切换。
3. **断层 ③ 临界失稳与脆性断裂断层 $\rightarrow$ 200~500 Hz 高危过程打分与毫秒级反射恢复（70% 算法 ②）**
   - 解耦“动作生成”与“物理状态裁判”，在 **128GB DGX Spark** 上以高频运行过程打分器，实时监测`空滑 / 正确进缝进气 / 顶死脆边危险 / 微裂纹前兆 / 卡扣崩开突跳`，在 `< 5 ms` 内触发退让、降角或瞬态卸力恢复。

| 任务编号 | 任务名称 | 核心物理难点与纯视觉 VLA 失败对比 |
| :--- | :--- | :--- |
| **Demo 1（旗舰主线）** | **手机透明膜贴合 + 赶气泡** | 全透明镜面深度失效；对比 PET 软膜与钢化膜，靠边缘微触觉定位 + 六维力/声振恒力匀速赶泡 |
| **Demo 2（旗舰主线）** | **0.2 mm 盲缝无损撬边起角** | 透明边缘融为一体；靠薄钢撬片 20 kHz 声振+应变分辨空滑/顶死脆边/切入胶层进气，绝不崩边划屏 |
| **Demo 3（旗舰主线）** | **防脆断稳态完整揭膜** | 钢化膜弯曲过陡必碎成蜘蛛网、软膜易皱；靠剥离张力 + 声学微裂纹前兆闭环控角完整取下 |
| **Demo 4（实验室泛化）** | **超脆硅片无损铲取与镊夹** | 同一套听诊夹爪与算法零样本迁移至实验室超薄脆硅片（薄钢刮刀无损铲起 / 普通尖镊子无损夹翻） |
| **Demo 5（失稳泛化）** | **金属撬棒撬电子卡扣防过冲** | 塑料外壳内紧贴缝隙放置脆硅片充当脆弱主板；卡扣崩开 5 ms 内感知突跳瞬间卸力，内部硅片完好 |

### 快速校核：运行撬片力学与脆膜/硅片防断弯曲半径计算器
```bash
python scripts/tool_and_peel_mechanics.py
```
该脚本可一键算出：
1. 不同厚度薄钢撬片在贴屏撬边载荷下的弹性挠度、弯曲安全系数及 MuJoCo 等效根部铰链刚度 $k_\theta$；
2. **PET 软膜、0.30 mm 钢化玻璃膜、0.20/0.50 mm 脆硅片**在不发生脆性断裂下的**最小允许弯曲半径 $R_{\min}$**（直接作为揭膜剥离角控制的物理硬约束）；
3. 不同倾角下的贴屏几何避碰间隙。
