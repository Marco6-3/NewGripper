# NewGripper: Bio-Inspired Asymmetric Nail-Pad Gripper & Physical Intelligence for Thin-Sheet Manipulation

> **项目定位**：面向 **极薄弹性片材（扑克牌、硬质卡片、纸张、薄膜、单层布料/工业薄片）** 的**仿生形态协同（30% 机电）与主动物理智能操控（70% 算法）**研究平台。  
> **目标里程碑**：1 年内冲击机器人顶会（冲刺 **CoRL 2027** / 主攻 **ICRA 2028**）。

---

## 1. 为什么做这个课题？（核心物理痛点）

当前主流的 VLA（Vision-Language-Action）与纯视觉模仿学习高度依赖 2D 语义先验，在面对**“视觉高度相似、物理动力学截然不同”**的极薄平面物体时存在根本性瓶颈：

- **无桌边平桌拾取与翻面（Zero-Edge Picking & Flipping）**：将一张 0.3 mm 厚的扑克牌或银行卡平放在光滑玻璃桌或木桌正中央（远离桌边），传统刚体平行夹爪与纯视觉策略几乎无法稳定拾取，更无法原地翻面。
- **物理策略随隐藏属性 180° 翻转**：
  - 高摩擦垫 + 软牌/纸张 $\rightarrow$ 需施加法向压力 + 切向挤压触发**弹性屈曲起拱（Buckling）**；
  - 光滑玻璃桌 / 硬质银行卡 $\rightarrow$ 挤压只会打滑，需**单指锚定 + 仿生薄指甲低摩擦楔入（Anchor-and-Wedge）**；
  - 叠放多张扑克/带静电粘连纸张 $\rightarrow$ 需精细控制法向-切向力比完成**单张剥离（Singulation）**并在线检测防双张粘连。
- **科研与工业双价值**：对外展现最具视觉震撼力的日常物理直觉（无桌边翻扑克牌、抗粘连发牌、跨材质薄片操控），同时天然对应工业场景中的**半导体薄片、新能源极片与纺织单层布料分离**痛点。

## 2. 系统总体方案（30% 现成改装机电 + 70% 物理智能算法）

### 2.1 硬件平台（20,000 RMB 预算，“现成工业底盘 + 科研级快换指尖”）
依托实验室采购的**工业协作臂（重复精度 ±0.05 mm，自带腕部六维力传感器）**、**多卡 A100** 与 **128GB DGX Spark**，2 万元末端预算全部投入**“采集-部署物理同构的非对称仿生双指系统”**：

- **零背隙现成底座**：高精度平行电爪（如大寰 PGE-50-40 / AG-95 级，±0.02 mm 精度，支持实时力位闭环）。
- **左指（仿生感知指甲指 — 核心创新）**：
  - 同一手指通过**接触倾角 $\alpha$** 无缝切换**柔软高摩擦硅胶指腹**与**薄弹性悬臂指甲刃（0.15~0.3 mm 301 不锈钢弹片 / 碳纤 / PEEK）**；
  - 弹性悬臂结构被动吃掉工业臂 ±0.5 mm 的 Z 轴贴桌误差，保护桌面与机械臂；
  - 指甲背面集成**金属箔应变片 + 高频 PVDF 压电膜（≥1 kHz 采样）**，捕捉 0.3 mm 牌边碰撞与弹起瞬态，补齐大六维力传感器底噪盲区。
- **右指（微观视触觉 + 主动微搓模块）**：
  - 现成微型视触觉传感器（GelSight Mini / DIGIT 级），直接观测微米级滑移、起拱边缘与多张粘连；
  - 可快换 18 g 微型总线舵机（Dynamixel XL330）驱动硅胶搓轮，实现单张捻牌剥离与指间原地翻面。
- **采集-部署 100% 物理同构**：同一对快换指尖 + 腕部超近景相机（RealSense D405）可快速拆装至轻量 3D 打印手持 UMI 手柄（配位姿追踪），高效采集人类“手感”数据。

### 2.2 核心算法（70% 科研重心）
1. **薄片屈曲与多层摩擦仿真 + Real-to-Sim 对齐**：在 MuJoCo / Isaac Lab 中建立可调弯曲刚度 $EI$ 与摩擦系数 $\mu$ 的薄片与弹性指甲仿真，用真机三层感知数据对齐动力学残差。
2. **主动微试探与物理隐变量 $z$（Active Tactile Probing）**：接触后前 0.2~0.3 s 执行微小探针动作，在线辨识 $z = (\hat{\mu}_{\text{table}}, \hat{\mu}_{\text{sheet}}, \widehat{EI})$，自动切换起拱 / 楔入 / 微搓手法。
3. **接触相变过程打分器（Phase & Multi-Sheet Scorer）**：实时评估接触进度与异常状态（打滑 / 铲空 / 双张粘连），触发在线纠错恢复（Recovery）。
4. **仿真引导的软硬件联合优化（Simulation-Guided Co-Design）**：联合优化指甲长度、厚度（刚度）、楔角与指腹软度，并用真机多组快换指尖做消融验证。

## 4. 仓库结构与当前工作流

当前第一阶段目标：**先基于真实商用件模型完成三维 CAD 装配与几何/力学可行性校核 $\rightarrow$ 导出 URDF/MJCF 在仿真中跑通核心物理动作，确认合理后再批量下单加工。**

```text
NewGripper/
├── README.md                              # 项目总览与路线图
├── configs/
│   └── gripper_params.yaml                # 真实硬件尺寸、力学参数、薄片/桌面参数与 Co-Design 搜索范围
├── docs/
│   ├── 01_hardware_design_and_bom.md      # 2万元现成改装 BOM、真实件接口规格与 8 项 CAD 可行性校核清单
│   ├── 02_research_plan_and_algorithms.md # 70% 算法架构、实验矩阵与 10 个月顶会倒推计划
│   └── 03_simulation_modeling_spec.md     # CAD -> URDF/MJCF 导出规范与仿真可行性 4 项物理单元测试
├── scripts/
│   └── nail_mechanics_check.py            # 悬臂指甲力学计算器（挠度/屈服安全系数/贴桌倾角避碰校核）
├── cad/                                   # 真实外购件 STEP 与自制快换指座 CAD（SolidWorks / Fusion360）
├── assets/                                # 导出给 MuJoCo / Isaac Lab 的 URDF / MJCF / Mesh 文件
└── sim/                                   # 仿真环境、物理单元测试与算法代码
```

### 快速开始：先运行指甲力学与贴桌间隙校核脚本
```bash
python scripts/nail_mechanics_check.py
```
该脚本会基于欧拉-伯努利悬臂梁理论，自动校核不同厚度（0.10 ~ 0.30 mm）弹簧钢/碳纤/PEEK 仿生指甲在 1~5 N 法向载荷下的**弹性挠度（Z 轴误差吸收能力）、根部最大弯曲应力、抗塑性变形安全系数**，以及**不同手指倾角下的贴桌几何避碰间隙**，直接指导 CAD 建模。
